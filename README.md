# AI Prompting Challenge

A dependency-free local browser prototype for Build With AI Hackathon #2.

## Features

- Beginner, Practical, and Advanced challenge modes with weak-prompt samples.
- Write an improved prompt and receive seven-element checklist feedback.
- Compare with a stronger sample prompt and copy your improved version.

## Run Locally

Open `index.html` in a browser, or serve this folder over localhost:

```bash
python -m http.server 8080 --bind 127.0.0.1
```

Open `http://127.0.0.1:8080/`. No dependency installation, account, API key, or paid service is needed. The app uses plain HTML, CSS, and JavaScript with no external network calls, telemetry, or input storage. Clipboard availability depends on the browser; use the displayed fallback selection when necessary.

## Limitations

A learning challenge with rule-based feedback; the score is a practice aid, not a measure of response quality. It remains distinct from the prompt composition app. Book 19 is source reference only; manuscript and publishing assets are excluded.
