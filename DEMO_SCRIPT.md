# Demo Script

Target length: under three minutes.

## 0:00 - 0:20 Open

Show `index.html` opened locally. State that AI Prompting Challenge helps users practice improving vague prompts.

## 0:20 - 0:45 Pick A Mode

Choose Beginner, Practical, or Advanced. Click `Load sample` and show the weak prompt.

## 0:45 - 1:15 Identify Gaps

Point out the missing-elements checklist. Check the gaps the weak prompt has, such as context, constraints, audience, output format, and review criteria.

## 1:15 - 1:50 Improve And Analyze

Show the improved prompt area, then click `Analyze prompt`. Explain the score and checklist feedback.

## 1:50 - 2:25 Compare Stronger Version

Click `Show stronger version`. Compare the user's improved prompt with the structured sample.

## 2:25 - 2:55 Boundaries

Close by noting that the prototype runs locally, does not call an AI service, does not store input, and uses Book 19 only as a source reference.
